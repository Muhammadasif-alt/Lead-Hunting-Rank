# Screen #3: Lead Hunter — Market Discovery Engine

## 1. Lead Hunter Home
Simple: "What market do you want to find?" + [Hunt Leads]. Advanced: Search Mode — Quick Hunt / Deep Hunt / **Market Exhaust** (multiple sources + query variations until meaningful new unique businesses sharply reduce; high practical coverage, no fake "100% complete").

## 2. Location Targeting
Country/State/City, Target type: City/Radius/ZIP/County/Multiple Cities/Custom Territory. Radius 5/10/25/50/custom miles. Multi-city include/exclude. Later: draw territory on map.

## 3. Industry Intelligence
Primary industry + related categories (Landscaper, Landscape Designer, Lawn Care, Lawn Maintenance, Landscape Architect, Irrigation, Tree Service, Garden Maintenance, Hardscaping, Outdoor Lighting, Turf Installation). AI query expansion + user control on breadth.

## 4. Discovery Sources
Provider-independent. Sources: search/map, business directories, industry directories, company websites, public business pages, public social profiles, approved data providers, existing CRM, other permitted public sources. Provenance per lead: Source A/B/Website/Directory + last verified. 4 sources same company → 1 company.

## 5. Smart Deduplication
Match signals: phone, domain, address, name, social, owner, coordinates, email. 98%+ → auto merge. Low confidence → human review.

## 6. Live Market Hunt
Live counters: discovered, unique, duplicates merged, with/without website, phone, email, social, decision maker, verified contact. Live activity feed.

## 7. Search Saturation
Rounds with +N new businesses each until ~0. Coverage Confidence "HIGH" — not "100% found".

## 8. Business Discovery Table
Business/Website/Owner/Email/Social/Score table. Powerful filters: website (none/has/poor/outdated), owner found/missing, verified email/phone, social (FB/IG/LI), reviews>50, rating>4, active only.

## 9. Website Discovery
Official vs directory vs Facebook-as-website vs broken/parked/wrong company. Statuses: Verified Official / None Found / Broken / Parked / Uncertain.

## 10. Website Intelligence
Audit: SSL, mobile friendly, contact form, booking, live chat, AI chat, quote request, analytics, conversion tracking, review integration, social links, blog. Tech detect (CMS/Analytics/Chat/Booking/CRM) — only reliably detectable = fact.

## 11. Website Opportunity Engine
Opportunities: redesign/booking/AI chat/local SEO/review automation/lead follow-up with Why + Evidence + Hypothesis + Confidence. Fact vs inference separate.

## 12. No-Website Intelligence
High-value no-website subset: businesses with strong reviews+social but no official website.

## 13. Social Intelligence
Facebook/Instagram/LinkedIn/other public profiles with match confidence + evidence. No blind guessing.

## 14. Owner / Decision Maker Finder
Business/professional prospecting data only, not personal data. Confidence HIGH/MED + sources.

## 15. Contact Verification
Statuses: Verified / Likely / Risky / Catch-all / Invalid / Unknown. Campaign eligibility rules per status.

## 16. Review Intelligence
Rating, count, recent activity, owner responses, common themes. Internal opportunity intel only — no creepy outreach.

## 17. Business Activity / Health Signals
Likely Active / Possibly Closed / Temporarily Closed / Uncertain based on reviews, social, website, listing, phone. Closed excluded.

## 18. Prospect 360 Preview
Hover/click: ICP/Opportunity/Contactability/Data Confidence scores, website/social, reviews, owner, email, phone, top opportunities, actions.

## 19. Multi-Dimensional Scoring
ICP / Opportunity / Intent / Contactability / Data Confidence + Priority, with explanation on click.

## 20. Smart Segments
Auto segments (No Website + 50 reviews, Poor Website + Active, No Booking + High Reviews, Owner + Verified Email, FB Active + No Website, High Digital Opportunity). Custom NL segment query.

## 21. Competitive / Market Intelligence
Market-level report: businesses mapped, website penetration %, no-website %, booking %, chat %, social %, average reviews, top digital gaps.

## 22. Territory Comparison
Austin vs Dallas vs Houston metrics; AI explains observed characteristics.

## 23. Saved Markets
Living dataset: last scan, new businesses, closed, new owners, websites launched, new opportunities. Continuous monitoring.

## 24. Change Detection
E.g., no website → new website detected → update profile + cancel stale "no website" messaging.

## 25. Deep Research
[Deep Research] button on high-value leads → full agent report.

## 26. Exclusion Engine
Permanently closed / duplicate / existing customer / unsubscribed / blacklisted / outside territory / wrong industry / invalid contact / do-not-contact. Suppression global.

## 27. Lead Hunter → Campaign handoff
Filter: 1086 → 327 high-fit → 167 opportunity → 121 contactable → segment → research validation → campaign strategy → approved outreach. Recommended controlled cohort of 25 first.

## 28. Lead Hunter Agent View
Agents status list (Market Discovery, Deduplication, Website Finder, Social Finder, Decision Maker, Enrichment, Verifier, Website Auditor, Opportunity Agent). Hideable for normal users.

## 29. Cost Control
Discover → dedupe → filter → basic score → enrich only promising. Est. enrichment candidates, high priority, recommended enrich-first.

## 30. Data Confidence
Every important field: value + confidence (HIGH/VERIFIED/MEDIUM).

## 31. "Find More" Engine
AI tries unexplored source/query combinations, not same query repeat.

## 32. Market Exhaust completion
Unique businesses, rounds, sources, query variations, duplicates removed, coverage confidence HIGH, last rounds +N. [Save Market] [Analyze Opportunities] [Build Segment].

## 33. Real differentiator
DEFINE MARKET → DISCOVER → EXPAND SEARCH → RESOLVE → DEDUPE → VERIFY ACTIVE → WEBSITE → SOCIAL → DECISION MAKERS → ENRICHMENT → VERIFICATION → DIGITAL AUDIT → SIGNALS → OPPORTUNITY → SCORING → SEGMENTATION → MONITORING → OUTREACH.
