# Screen #5: Conversations / AI Inbox

## Core principle
Every incoming message → understand context → classify intent → update memory → cancel/adjust automation → decide next action → respond or escalate.

## 1. Main Screen
3-panel: INBOX list | CONVERSATION thread | INTELLIGENCE (intent, ICP, opportunity, qualification, next action, Company 360 link). Search + AI ● ACTIVE indicator.

## 2. Smart Inbox Categories
🔥 High Intent / ⚡ Needs Human / 🟢 Interested / 🟣 Meeting Requested / ❓ Questions / 💰 Pricing / 🛡 Objections / 🕒 Not Now / ↪ Referral / 🤖 AI Handling / ⏳ Waiting on Prospect / 📤 Waiting on Us / ⚠ Uncertain / 🚫 Opt-outs / ✓ Resolved.

## 3. Priority Inbox
Priority = intent + opportunity value + urgency + stage + promises/deadlines + relationship + human requirement + waiting time, not unread time.

## 4. Incoming Reply Pipeline
Message → identify sender → resolve company/contact → find conversation → load Company 360 → load prospect memory → load previous → load campaign → cancel conflicting scheduled messages → classify intent → extract facts → detect questions → detect objections → update qualification → Next Best Action → Policy → AUTO/HUMAN/WAIT/STOP.

## 5. Instant Sequence Stop
Reply aayi → Day 3/Day 7 follow-ups cancelled. No awkward automated FU.

## 6. Multi-intent classification
Primary + secondary intents + sentiment + questions[] + confidence.

## 7. Intent Taxonomy
Interested, Very Interested, Question, Pricing, Portfolio Request, Meeting Request, Technical Question, Feature Question, Objection, Not Now, Referral, Wrong Person, Already Has Solution, No Need, No Budget, Competitor, Negative, Unsubscribe, Out of Office, Auto Reply, Bounce, Spam, Unknown.

## 8. Out-of-Office
Return date parsed → not human reply, not positive/negative, pause sequence, eligibility after return.

## 9. Not Now
→ re-engagement date → memory → pause → before contact: refresh business/person/website/signals/context → contextual FU.

## 10. Wrong Person / Referral
Store referral, find person, verify, preserve context, stop original sequence. Respectful reference only.

## 11. Unsubscribe
No persuasion. Stop outreach, cancel FU, suppression, audit. AI cannot override.

## 12. Question Detection
Extract Q1/Q2 → KB search → approved answer available? → respond. Not found → DO NOT INVENT → Ask human.

## 13. Grounded AI Replies
System policies → company knowledge → product knowledge → pricing rules → Company 360 → prospect memory → history → current message → response.

## 14. Reply Preview
Proposed response + answer confidence + policy compliance + pricing authority + claims grounded + unanswered questions → AUTO SEND / human. Autonomous mode: audit save, no popup.

## 15. AI Control per conversation
AUTO / ASSIST (draft+approve) / HUMAN (no reply, but suggestions+summary). Switch any time.

## 16. Human Takeover
Pause AI outbound + AI actions; incoming analyzed; memory updated; suggestions available. [Return to AI] → AI sees human messages in context.

## 17. Smart Compose for humans
Draft Reply / Shorter / More Professional / Answer Questions / Handle Objection / Suggest Meeting — inside approved knowledge.

## 18. Objection Engine
Objection type + confidence + context + strategy + authority (AUTO allowed). Non-pushy.

## 19. Objection Memory
Structured: Oct 2 already-has-provider, partial resolution, response, outcome. Revenue intelligence correlates objection→meeting conversion.

## 20. Pricing Engine
Approved range only. AI cannot create discount/custom price/change terms. >$500 ask → discount request → human escalation.

## 21. Negotiation Guardrails
Price info AUTO / standard package AUTO / custom quote DRAFT / discount HUMAN / payment terms HUMAN / contract HUMAN / legal HUMAN / guarantee HUMAN. Configurable.

## 22. Sentiment
Tone signal Positive/Neutral/Negative/Uncertain — not fake emotion detection.

## 23. Qualification During Conversation
Need/Authority/Timeline/Budget/etc extracted; unknowns tracked; AI not interrogative; ask natural missing info only.

## 24. Conversation Goal
Cold → Establish Relevance → Understand Need → Qualify → Resolve Questions → Meeting. AI not endless chatting.

## 25. Meeting Detection
Meeting intent → prospect preference → check assigned salesperson availability → offer valid slots.

## 26. Calendar context
AI knows availability → offers slots → auto book if authorized.

## 27. Meeting Confirmation
Calendar event, confirmation email, opportunity updated, cold outreach stopped, goal completed, brief scheduled.

## 28. Multi-Channel Thread
Email/chat/SMS same prospect ideally one relationship timeline, respect channel consent/rules.

## 29. Channel Switching
Only with permission/consent/rules/prospect preference.

## 30. Memory Extraction
New facts with provenance (Email Oct 2 10:42).

## 31. Contradiction Detection
Latest prospect statement supersedes; history preserved.

## 32. Promise Detection
Send case study → due tomorrow → tracked → promise due alert.

## 33. Risk Detector
Legal/contract/refund/custom pricing/low confidence/asks for human → escalate.

## 34. Human Attention Queue
NEEDS YOU: custom pricing 2, proposal 1, AI uncertain 1, high-value 1, human requested 1.

## 35. SLA / Response Intelligence
Prospect waiting 4 min HIGH / human-required 43 min → notify. Escalation rules.

## 36. Duplicate Conversation Prevention
Sender/company/subject/recent context/identifiers → link or human review.

## 37. Conversation Search
NL queries: pricing asked this month, landscapers interested no meeting, waiting on us, contact me later, needs human.

## 38. Conversation Summary
40-message thread → 10-second summary.

## 39. "Catch Me Up"
What changed since last viewed.

## 40. Explainability
DECISION → WHY → rule. Not raw chain-of-thought.

## 41. Thread Actions
Take Over / Book Meeting / Create Opportunity / Assign / Snooze / Mark Resolved / Do Not Contact.

## 42. Assignment
Technical→tech sales, high-value→senior, existing→owner, general→AI, uncertain→human queue.

## 43. Internal Collaboration
@Mike notes inside thread; not sent to prospect; AI knows internal.

## 44. Event Timeline
10:21 received, classified, FU cancelled, memory updated, draft, policy, sent, next action.

## 45. AI Quality Review
Grounded/questions/tone/policy/unapproved claim audit. Flag → human review → root cause → KB/policy improvement.

## 46. Feedback
👍/👎 + why (incorrect info/too long/pushy/tone/missed question/should escalate/other) → controlled learning data.

## 47. Conversation Intelligence Dashboard
Replies/positive/qualified/meetings, top questions, top objections, escalation %, AI resolved %.

## 48. Conversation State Machine
COLD → CONTACTED → REPLIED → ENGAGED → QUALIFYING → QUALIFIED → MEETING REQUESTED → MEETING BOOKED. Exits: NOT NOW→NURTURE, NOT FIT→CLOSED, UNSUBSCRIBE→SUPPRESSED, NO RESPONSE, HUMAN NEEDED→ESCALATED.

## 49. Ultimate Inbox Principle
Not "which messages unread?" but "which relationships require an action, and who should take that action?".
