# Screen #02 — AI Sales Manager

## 1. Core Purpose
Goal → Understand → Analyze → Build Plan → Delegate to Agents → Monitor Execution → Detect Problems → Recommend/Act → Measure Outcome → Learn. Chat = control interface, not giant chatbot window.

## 2. Not Chat window
Combines: AI Conversation + Goals + Plans + Missions + Agents + Decisions + Recommendations + Performance + Human Approvals.

## 3. Layout
Header (● ACTIVE, Level 3). Tabs: Overview/Goals/Missions/Agents/Decisions/Memory. NL input. Left: CURRENT GOALS, ACTIVE MISSIONS, AGENT ACTIVITY. Right: MANAGER BRIEFING, HUMAN DECISIONS, RECOMMENDATIONS. TODAY'S PLAN.

## 4. NL Commands
Find new market / Austin ka kya haal / important today / why meetings low / opportunities needing attention / Dallas 500 landscaping / stop contacting active conversations / tomorrow's plan / where losing prospects / what to focus this week.

## 5. Intent Router
Request → Intent → Read/Analyze/Plan/Act → Scope → Authority → Policy → Execute/Preview/Approval. Send pause → resolve intent → campaign → user authority → impact → execute per policy.

## 6-8. Read/Analyze/Action commands
Direct answers from data / bottleneck diagnosis (discovery→contactability→delivery→replies→positive→qualification→meeting requests→bookings) / create mission with location+industry+mode+budget+permissions+policy.

## 9. High-Impact Commands
"5000 emails bhej do" → preview plan: audience 5042, potential new contacts 4718, volume, current authority 500 without approval → start validation cohort.

## 10-21. Goal Center
Goal: Generate qualified sales opportunities, service, territory, owner, autonomy level, started. Goal types: Market Coverage/Qualified Meetings/Opportunities/Pipeline/Re-engagement/Account Expansion/Research/Data Improvement — NOT "send 10,000 emails". Constraints: market/industry/service/channel/max contacts/daily/budget/duration/forbidden. Feasibility = plan, not promise. Progress = full funnel. Multiple goals with budget/concurrency limits. Priority: Critical/High/Normal/Low.

## 17-19. AI Planner + Visualization + Dependencies
Goal → plan steps (map market → resolve duplicates → audit presence → identify segments → decision makers → verify contacts → rank → campaign strategy → validation cohort → monitor → qualify → book → opportunities → measure). Visualization linear, no fake %. Dependencies enforced.

## 20-23. Mission Concept
Goal = desired outcome. Mission = operational work. Mission card: status, companies, completed, needs review, failed, remaining, budget used. States: DRAFT/READY/RUNNING/WAITING/BLOCKED/PAUSED/COMPLETED/CANCELLED/FAILED. Ownership: AI/Human/Hybrid.

## 24-27. Agent Orchestrator
AI Sales Manager delegates: Market Hunter/Research/Signal/Contact/Campaign/Conversation/Qualification/Scheduling/Learning. Status panel: active/waiting/idle + health vs activity. Agent detail: health, mode, current work, queue, completed today, escalations, spend, authority. Idle ≠ failed.

## 28-29. AI Decision Inbox
Campaign expansion, market expansion, strategy change, pricing exception, proposal, high-risk reply, experiment, budget increase, knowledge update, AI policy change.

## 30. Recommendation ≠ Decision
Recommendation = suggest. Decision = asking permission to spend/act.

## 31-32. AI Recommendations with evidence
WHY + EVIDENCE + scope + confidence + actions. "Evidence first" — show sample sizes, may not generalize.

## 33-34. Strategy Memory
Validated scoped strategy knowledge; separate from prospect memory (Screen #12).

## 35-38. Manager Briefing
Since yesterday: discovered/verified/replies/qualified/meetings/opportunity. Needs attention list. Bottleneck. Periods: Today/Since last login/Yesterday/Week/Month/Custom. Morning brief feeds Screen #1. End-of-day review.

## 39-42. Daily Autonomous Planning
Goals→state→commitments→meetings→campaigns→markets→budget→policies→today's plan. Plan: HIGH PRIORITY human items, AUTONOMOUS, BACKGROUND. Dynamic replanning on high-value events within policy. Priority Engine: revenue impact/urgency/relationship/deadline/waiting/meeting proximity/stage/goal importance/dependency/system risk.

## 43-44. Next Best Action + What Would You Do
Context-specific recommendation with WHY. Execute only when authorized.

## 45-46. Scenario Simulator
Constraints-based estimates: current limits, audience, cost, policy impact. Compare options A/B/C. No false certainty.

## 47-49. NL Analytics + Funnel Diagnosis + Bottleneck
Actual data with caveats. Funnel diagnosis: delivered→replies→positive→qualification→meeting offered→booked. Bottleneck types: market/contact/verification/deliverability/reply quality/qualification/scheduling/proposal/human approval.

## 50-52. Human/AI/Data Bottlenecks
Human: approvals waiting, proposal delays. AI: knowledge gaps causing escalations. Data: no verified contact blocking outreach → deeper enrichment proposal with cost.

## 53-57. Budget Manager
Today's use: AI/Research/Enrichment/Verification spend, outbound used/limit. AI Action budget: contacts/day, deep research/day, enrichments/day, sends/day, FU/day, active missions, concurrent markets. Reallocation proposal with human approval. Cost awareness per mission. Stop-loss: max spend/companies/sends/runtime/search rounds → mission paused.

## 58-61. Opportunity Manager + Intervention + Relationship Awareness + Account Strategy
Top opportunities with pipeline value. Detect stale proposals (6 days, no response, no follow-up) → recommendation. Check existing opportunity/customer/conversation/DNC/human owner before cold outreach recommendation. Account-level stakeholder visibility without mass-contacting active account.

## 62-64. Market Manager + Expansion + Market Exhaust Supervision
Active territories metrics; budget/verified contacts/qualified conversations per market. Recommendation to finish current segment before expanding. Supervision of sources/queries/new unique per round/duplicates/coverage confidence/cost → continue/stop round decision.

## 65-66. Campaign Supervision + Auto-Pause
Campaign health: audience/cohort/replies/qualified/meetings/pipeline/deliverability/human blocks. Recommendations: Continue/Pause/Expand/Investigate/Experiment. Auto-pause triggers: bounce threshold, provider incident, suppression issue, unexpected error, policy violation, data quality issue.

## 67-68. Conversation/Meeting Supervision
Manager watches high-value conversations, repeated objections, escalations, knowledge gaps, pricing, relationship risk. Meetings: today's count, brief readiness, missing info, no-show, follow-up required.

## 69-70. Knowledge/Learning Supervision
Knowledge gaps (ServiceTitan asked by 5 prospects, no KB answer) → route to #13/#14. Experiment outcomes review before broad deployment. No silent global strategy rewrite.

## 71-72. Negative Learning + Controlled Improvement
Example: no-contact segment consumed research budget, no engagement → lower enrichment priority. Recommendation → Experiment → Measure → Review → Deploy.

## 73-75. Manager Memory
Goals/past missions/human decisions/approved+rejected strategy/experiment outcomes/recurring bottlenecks/priorities. Human decisions stored with scope/date/reason; some permanent, some temporary with effective period.

## 76-79. Explainability + Why Did You/Didn't/Need Me
WHAT+WHY+EVIDENCE+SCOPE+CONFIDENCE+IMPACT+AUTHORITY. No private chain-of-thought dump. "Why did you stop campaign?" → policy trace. "Follow-up kyun nahi?" → prospect replied, sequence cancelled. "Custom pricing?" → human-only authority.

## 80-82. Confidence/Conflicting Evidence/Freshness
KNOWN / LIKELY / UNKNOWN. Conflicting owner sources → status CONFLICT → reverify. Stale owner data 11 months → revalidate first.

## 83-87. Approval/Takeover/Return/Control/Emergency
Approval request → #14 → authorized human → approved/edited/rejected → mission continues. [TAKE OVER] pauses conflicting external action. [RETURN TO AI] re-evaluate current state/conversation/promises/opportunity/policies. Manager cannot expand its own authority; opens #17. [PAUSE AI] [PAUSE OUTREACH] always accessible, human overrides AI.

## 88-90. System Health Awareness + Failure Recovery + Mission Incident
Gmail degraded → outbound paused, research/inbound continue. Calendar unhealthy → no unverified meeting offers. Failed step → check retryable/alternative provider/can continue/human required. Mission issue: provider auth failed, blast radius shown.

## 91-94. Activity Timeline + Decision History + Goal Timeline + Analytics
Manager timeline entries. Decision history: approved/rejected/edited with who. Goal narrative timeline. Management metrics: goals active/missions running/human blocks/autonomous actions/meetings/qualified/pipeline/spend.

## 95-98. AI vs Human Contribution + Search + Notifications + Role Awareness
No simplistic "AI generated $50K"; show contribution chain. Search across goals/missions/decisions/recommendations/agent activity/strategy memories. Notify only: mission blocked, goal materially off, human approval, critical failure, budget boundary, high-value escalation, safety incident. Owner can change budget; sales user → request approval per #16.

## 99. Home Final UI
Header + nl input + suggestions. Left: Manager Briefing, Current Goals, Active Missions, Recommendations, Recent Manager Activity. Right: Needs Your Decision, Today's Plan, AI Team, Goal Progress.

## 100. Goal Detail Page
Goal overview + Autonomy L3 + Plan/Missions/Market/Campaigns/Conversations/Opportunities/Decisions/Learning tabs + full funnel.

## 101-102. Decision Loop + AI Capability ≠ AI Authority
Loop: Human goal → Manager understands → constraints → plan → missions → agents execute → events → working? → problem? → diagnose → can AI solve? → act/human → outcome → learning → propose improvement → policy/experiment → replan.

## 103-106. Relationship to Other Screens + Command Center vs Manager + Backend Model + Final Experience
Coordinates #03-#17 but doesn't duplicate. Command Center = Mission Control (what's happening, what needs me). Manager = Sales Brain (what to achieve, what to do, who, why, what to change). Backend: Goal→Plan→Mission→Agent Task→Action Proposal→Policy→Job→Execution→Event→Outcome→Evaluation. User: "Mujhe Austin ke landscapers se website redesign clients chahiye" → Manager proposes plan → approval → orchestration.
